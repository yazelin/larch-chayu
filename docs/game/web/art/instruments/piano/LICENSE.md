# Salamander Grand Piano

鋼琴錄音由 Alexander Holm 製作，採用 [CC BY 3.0 Unported](https://creativecommons.org/licenses/by/3.0/) 授權。

- [Alexander Holm 的發表頁](https://rytmenpinne.wordpress.com/sounds-and-such/salamander-grandpiano/)
- [Salamander Grand Piano 原始取樣庫](https://archive.org/details/SalamanderGrandPianoV3)
- [Tone.js 隨檔說明及授權](https://github.com/Tonejs/audio/blob/master/salamander/README)
- [本專案使用的 Tone.js 音檔來源](https://github.com/Tonejs/audio/tree/master/salamander)

本專案取用每小三度一個音的錄音，保留琴鍵 C3 至 C6 與上下相鄰的 A2、升 D6，共 15 個音。來源是 Tone.js 託管的 160 kbps Ogg Vorbis 版（https://tonejs.github.io/audio/salamander/），擷取左聲道轉為單聲道，以 96 kbps 重新編碼為 MP3，保留每段錄音的完整長度。
